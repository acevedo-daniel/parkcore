# Security

ParkCore is a public portfolio project and technical demo, not a commercial service. The deployed app is a demonstration intended for fictional data and does not process payments. Do not enter real credentials that you use elsewhere, real customer information, or other sensitive personal data.

## Report a security issue

If GitHub Private Vulnerability Reporting is available, use [private vulnerability reporting for ParkCore](https://github.com/acevedo-daniel/parkcore/security/advisories/new). Do not post vulnerability details publicly. There is no promised response or resolution time.
