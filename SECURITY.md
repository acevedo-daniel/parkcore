# Security Policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting for ParkCore](https://github.com/acevedo-daniel/parkcore/security/advisories/new) to report suspected security vulnerabilities.

Do not open a public issue, pull request, or discussion for a vulnerability. Include enough detail to reproduce the issue, and do not share personal data or active credentials in the report.

## Supported versions

ParkCore currently supports the latest code on `main`. No older release line is maintained.

Security fixes are developed against the current source and delivered through the normal reviewed pull-request workflow.
