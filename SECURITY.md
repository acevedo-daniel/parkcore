# Security Policy

## Reporting a vulnerability

**Do not** open a public issue for security vulnerabilities.

Use GitHub Private Vulnerability Reporting, which is enabled for this repository:

- **GitHub:** [Report via GitHub Private Vulnerability Reporting](https://github.com/acevedo-daniel/parkcore/security/advisories/new)

### What to include

- Affected component and version
- Impact assessment
- Steps to reproduce or minimal proof of concept
- Known mitigations, if any

## Response expectations

Reports are reviewed on a best-effort basis.

## Supported versions

Only the latest version on `main` is supported.

## Scope

This policy covers the source code in this repository. Third-party dependencies should be reported to their respective maintainers.

## Recognition

Contributors who responsibly disclose valid vulnerabilities may be acknowledged in the security advisory unless they prefer to remain anonymous.
